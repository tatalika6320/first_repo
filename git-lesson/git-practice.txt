## Network basics

**HTTP** — правила передачі даних між клієнтом і сервером  
**HTTPS** — HTTP + шифрування (SSL/TLS)  

**DNS** — перекладає доменне імʼя в IP-адресу  
**IP** — адреса сервера  

**API** — спосіб отримувати дані із сервера (зазвичай JSON)  
**JSON** — формат передачі даних (не сторінка)

Цикл for:
- використовується, коли відома кількість повторень
- має початок, умову і крок
- безпечніший і найпопулярніший

Цикл while:
- використовується, коли кількість повторень невідома
- працює, поки умова true
- небезпечний без зміни умови

Якщо забути i++:
- цикл не закінчиться
- браузер зависне
